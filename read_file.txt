✅ Basic Tasks (Project-Oriented)
1.	Order Created → Log + Stock Update
    o	Event: OrderCreated
    o	Listeners:
        	LogOrderCreated → storage/logs/laravel.log mein order ID aur user ID save karo. ✅
        	UpdateProductStock → order hone par products table se ordered quantity stock se minus kar do. ✅
    o	Event: OrderDeleted
           RestoreProductStock → user ka order delete hona par wapis wo stock product main chale jaye.
    o	Goal: Order create hone ke sath hi backend updates ho jaayein.
2.	Payment Completed → Notify User
    o	Event: PaymentCompleted
    o	Listener: NotifyUserPayment
    o	Action: User ko email bhejna: “Payment successful for Order #ID.”
    o	Goal: Basic user communication.
________________________________________
🔹 Intermediate Tasks
3.	Payment Completed → Update Order Status
    o	Event: PaymentCompleted
    o	Listener: UpdateOrderStatus
    o	Action: Order ka status pending → paid.
4.	Order Created → Send Order Summary
    o	Event: OrderCreated
    o	Listener: SendOrderSummary
    o	Action: User ko email mein uske sabhi orders ki summary bhejna.
________________________________________
🔸 Advanced Tasks
5.	Large Payment Alert to Admin
    o	Event: PaymentCompleted
    o	Listener: NotifyAdminLargePayment
    o	Action: Agar payment amount > 10,000 ho → Admin ko email/notification.
6.	Queue Listener for Stock Updates
    o	Listener: UpdateProductStock ko queued bana do.
    o	Goal: Asynchronous background processing.
________________________________________
🚀 Extra Advanced Tasks

    o	LogOrderCreated, NotifyUserOrder, UpdateProductStock sab trigger ho ek sath.

    o	Event: PaymentCompleted
    o	Listener: BroadcastPaymentNotification
    o	Action: Laravel Echo channel par frontend ko live update show karna.

    o	Event: OrderUpdated
